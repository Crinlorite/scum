title: Connecting to the Familia Ruiz server
description: How to join the Familia Ruiz community SCUM server.
updated: 2026-05-30
---

The Familia Ruiz community server is always online. Connect by name or by direct address; the connection is stable.

## By name

1. Open SCUM → **Multiplayer** → **Community**.
2. Search for `Familia Ruiz` in the filter bar.
3. Double click to connect.

If it does not show up, jump to the direct method.

## By direct address

1. Open SCUM → **Multiplayer** → **Direct**.
2. Enter `server.scumcodex.com` and the game port.
3. Click **Join**.

## If it doesn't appear in the list

The Steam server browser's public list can take time to refresh. If you don't see it, connect by direct address — the connection works the same.
