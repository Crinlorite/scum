The server runs on a Hetzner VPS, in Docker under Wine. The connection is stable; the only thing that occasionally fails is the public listing.

## By name

1. Open SCUM → **Multiplayer** → **Community**.
2. Search for `Crintech Community SCUM` in the filter bar.
3. Double click to connect.

If it does not show up, jump to the direct method.

## By direct IP

1. Open SCUM → **Multiplayer** → **Direct**.
2. Enter the IP and port when published here.
3. Click **Join**.

## Why it sometimes does not show in the list

The server runs under **Wine** (Windows compatibility on Linux), and the A2S query — the mechanism Steam uses to list servers — is broken under that setup. The actual connection works perfectly, but the Steam master server can take time to refresh the entry.
